  `grid.md`.

  line about which elements can be nested, with a link.

  `color-mix()` and theming.

  non-Baseline features (`if()`, scroll-driven animations, masonry, customizable
  `<select>`, `reading-flow`) are out.

- Update `htmlCss.description` in `src/categories.ts` to list what is inside
  (e.g. "Semantic HTML, the cascade, box model, Flexbox, Grid, positioning,

## Pages

1. `cascade.md`, "Specificity and the Cascade", `[junior, middle]`, position 2.
   Answers: which rule wins when several apply, and why. Includes: cascade order
   (origin and `!important`, style attribute, layers, specificity, scope
   proximity, source order); specificity as (id, class, type) with a table;
   `:is()` / `:not()` / `:has()` take the most specific argument, `:where()` is
   zero, nesting `&` behaves like `:is()`; `@layer` order, unlayered beats
   layered, `!important` reverses layers; inheritance and `inherit` / `initial`
   / `unset` / `revert` / `revert-layer`; `@scope` in one line. Follow-ups:
   pseudo-class vs pseudo-element, `:has()` as a "parent selector", why avoid
   `!important`.
2. `box-model.md`, "Box Model", `[junior]`, position 3. Answers: how an
   element's size is calculated. Includes: content / padding / border / margin;
   `content-box` vs `border-box` and the global reset; margin collapsing and
   what stops it; block, inline, inline-block (moved from `html.md`); block
   formatting context and `display: flow-root`; `overflow`; `width: auto` vs
   `100%`; `aspect-ratio`; logical properties and why (RTL, writing modes).
3. `flexbox.md`, "Flexbox", `[junior, middle]`, position 4. Answers: how a flex
   container distributes space. Includes: main and cross axes; container and
   item properties in tables; `flex: 1` = `1 1 0%`, grow / shrink / basis;
   `gap`, `flex-wrap`; the `min-width: auto` overflow trap and `min-width: 0`;
   `order` and accessibility.
4. `grid.md`, "CSS Grid", `[junior, middle]`, position 5. Answers: how to build
   two-dimensional layouts and when to pick Grid over Flexbox. Includes: tracks
   and `fr`; `repeat(auto-fill | auto-fit, minmax())` and the difference; line
   placement and `grid-template-areas`; implicit grid and `grid-auto-flow`;
   subgrid; Grid vs Flexbox table; alignment only where it differs from Flexbox.
5. `positioning.md`, "Positioning and z-index", `[junior, middle]`, position 6.
   Answers: how `position` values differ and why `z-index` sometimes does not
   work. Includes: table of `static` / `relative` / `absolute` / `fixed` /
   `sticky`; containing block, including `transform` / `filter` on an ancestor
   trapping `fixed`; why `sticky` does not stick; stacking context and
   `isolation: isolate`; top layer (link); anchor positioning, short; centering
   table (flex/grid `place-items`, `margin: auto`, absolute with `inset: 0`,
   `translate`).
6. `responsive-design.md`, "Responsive Design", `[junior, middle]`, position 7.
   Answers: how a layout adapts to screen and container size. Includes:
   mobile-first `min-width` queries, range syntax, content-based breakpoints;
   units table (`px`, `em`, `rem`, `%`, `vw`, `dvh` / `svh` / `lvh`, `cqi`);
   `clamp()` / `min()` / `max()`; container queries (`container-type`,
   `@container`), style queries in one line; `srcset` / `sizes` vs `<picture>`;
   media features `hover` / `pointer`, `prefers-color-scheme`,
   `prefers-reduced-motion`.
7. `custom-properties.md`, "CSS Custom Properties", `[junior, middle]`,
   position 8. Answers: what CSS variables are and how they differ from Sass
   variables. Includes: declaration and `var()` with a fallback; they cascade
   and inherit, are resolved at computed-value time and can change at runtime
   (from JS too); invalid at computed-value time; `@property` (type,
   inheritance, initial value, animating); theming with `[data-theme='dark']`,
   `light-dark()` and `color-mix()`; Sass variables are compile-time.
